# 🌸 Floweria (Bloomopedia)

## Overview

Floweria is an Android application developed to help users learn about different flowers in a simple and interactive way. The application provides flower information, images, audio descriptions, and navigation support for multiple flowers.

## Activities

* MainActivity – Application home screen
* CategoryActivity – Displays flower categories
* FlowerListActivity – Shows flowers within a selected category
* FlowerDetailActivity – Displays detailed information about individual flowers
* AboutActivity – Provides information about the application

## Features

* Information for 20 different flowers
* Flower categories and flower details
* Flower images and descriptions
* Text-to-Speech (TTS) support for flower information
* Google Maps navigation for flower locations
* Multi-screen navigation
* Simple and user-friendly interface

## Technologies Used

* Java
* Android Studio
* XML
* Android SDK
* Text-to-Speech (TTS)
* Google Maps

## How to Run

1. Open the project in Android Studio.
2. Build and run the application on an emulator or Android device.
3. Select a flower category and explore flower information, audio descriptions, and navigation features.
